Installer Google Tag Manager sans développeur (WordPress, Wix, Shopify, Webflow)

Installer Google Tag Manager se fait en trois étapes : créer un compte gratuit, coller un petit code sur votre site, puis vérifier que tout répond avec l'outil de test de Google. Comptez 20 à 30 minutes, sans développeur, quel que soit votre site. Voici chaque étape, écran par écran.

Google Tag Manager, c'est quoi, et pourquoi il vous en faut un pour Google Ads

Google Tag Manager (GTM) est un outil gratuit de Google. En une phrase : c'est une boîte que l'on pose une seule fois sur son site, et qui permet ensuite d'ajouter ou de modifier tous les outils de mesure sans jamais retoucher le site.

Sans GTM, chaque réglage demande d'ouvrir le code du site. Pour un gérant de TPE, cela veut dire appeler un prestataire, attendre, payer. Avec GTM, les réglages se font dans une interface à boutons. Exemple : vous voulez compter les demandes de devis comme conversions Google Ads. Sans GTM, il faut modifier le site. Avec GTM, c'est une balise à créer dans l'interface, et le site n'est jamais touché.

Cette page couvre l'installation seule. Pour la suite (brancher les statistiques, compter les conversions, remonter les devis signés), notre guide complet pour apprendre Google Tag Manager pas à pas présente le parcours entier dans l'ordre.

Deux mots à connaître avant de commencer :

  • le conteneur : votre espace GTM pour un site donné. Un site = un conteneur ;
  • une balise : un petit programme rangé dans le conteneur, qui fait une action (prévenir Google Analytics d'une visite, par exemple).

Étape 1 : créer le compte et le conteneur

  1. Allez sur tagmanager.google.com et connectez-vous avec votre compte Google (celui de votre Gmail ou de votre compte Google Ads).
  2. Cliquez sur « Créer un compte ». Nom du compte : le nom de votre entreprise. Pays : France.
  3. Nom du conteneur : l'adresse de votre site, par exemple www.dupont-plomberie.fr.
  4. Plate-forme cible : choisissez « Web », puis cliquez sur « Créer » et acceptez les conditions.

GTM affiche alors une fenêtre « Installer Google Tag Manager » avec deux morceaux de code, et votre identifiant en haut à droite. Il ressemble à GTM-ABC1234. Notez-le : vous en aurez besoin à l'étape suivante.

Étape 2 : installer le code selon votre site

Suivez uniquement la ligne qui correspond à votre site. Dans tous les cas, l'opération se fait une seule fois.

ShopifyDans le fichier theme.liquid, en collant les deux codesMoyenne

WordPress : avec l'extension GTM4WP

  1. Dans votre administration WordPress : Extensions, puis Ajouter, puis cherchez « GTM4WP ».
  2. Cliquez sur Installer, puis Activer.
  3. Allez dans Réglages, puis « Google Tag Manager », collez votre identifiant GTM et enregistrez.

C'est tout. L'extension pose les deux morceaux de code au bon endroit, sur toutes les pages.

Wix, Shopify, Webflow : où coller le code

  • Wix : tableau de bord, puis Marketing et SEO, puis « Intégrations marketing », puis Google Tag Manager, et collez l'identifiant. Il faut un forfait payant avec un domaine connecté.
  • Shopify : Boutique en ligne, puis Thèmes, puis « Modifier le code », puis le fichier theme.liquid. Collez le premier code juste après la ligne <head>, et le second juste après <body>. Enregistrez.
  • Webflow : Paramètres du site, puis « Custom code ». Le premier code dans « Head code », le second dans « Footer code ». Enregistrez, puis publiez le site.

Votre site est fait sur mesure ou par un prestataire ? Envoyez-lui les deux codes affichés par GTM avec ce message : « à poser sur toutes les pages, le premier le plus haut possible dans le head, le second juste après l'ouverture du body ». C'est un travail de 10 minutes.

Étape 3 : vérifier que ça marche avec l'aperçu (Tag Assistant)

Ne sautez pas cette étape : un code mal posé ne prévient personne, il ne mesure rien, c'est tout.

  1. Dans GTM, cliquez sur « Prévisualiser », en haut à droite.
  2. Un onglet Tag Assistant s'ouvre (c'est l'outil de test de Google). Tapez l'adresse de votre site et cliquez sur « Connect ».
  3. Votre site s'ouvre dans une nouvelle fenêtre. Revenez sur l'onglet Tag Assistant : il doit afficher « Connecté ! » avec votre identifiant GTM.

Si vous voyez « Connecté ! », l'installation est bonne. Le conteneur est vide pour l'instant, c'est normal : les balises viennent après.

Les erreurs fréquentes

  • Deux GTM sur le même site. Une agence en avait posé un, vous en ajoutez un autre : certaines données partent en double, d'autres se perdent. Avant d'installer, vérifiez sur tagassistant.google.com si un conteneur existe déjà. S'il y en a un, demandez-en l'accès plutôt que d'en créer un deuxième.
  • Le code posé, mais jamais publié. Dans GTM, chaque modification reste en brouillon tant que vous n'avez pas cliqué sur « Envoyer » puis « Publier ». C'est l'oubli le plus courant.
  • Le cache qui masque le changement. Si votre site a une extension de cache (WP Rocket, LiteSpeed) ou passe par Cloudflare, videz le cache après l'installation, sinon Tag Assistant peut voir l'ancienne version du site.
  • Le code posé sur une seule page. GTM doit être sur toutes les pages, pas seulement l'accueil. Les extensions et les zones « code du site » le font automatiquement ; un collage à la main dans une seule page, non.

Et après ?

GTM posé et vérifié, votre boîte est en place, mais elle est vide. Elle ne compte encore ni les visites ni les demandes de devis. La suite logique, c'est l'étape suivante : suivre vos conversions Google Ads, pour que chaque demande de devis soit comptée, et seulement les vraies.

Questions fréquentes

Google Tag Manager est-il gratuit ?

Oui, entièrement. Google Tag Manager, Google Analytics 4 et Tag Assistant sont gratuits, quel que soit votre volume de visites. Vous payez seulement vos campagnes Google Ads, comme avant.

Est-ce que GTM ralentit mon site ?

L'effet est négligeable pour un site de TPE. Le code GTM se charge en parallèle du reste de la page. Ce qui peut ralentir un site, c'est d'y entasser des dizaines de balises inutiles. Avec les 3 ou 4 balises d'un suivi Google Ads propre, la différence ne se voit pas.

Mon agence a déjà posé Google Tag Manager. Je fais quoi ?

Ne posez surtout pas un deuxième conteneur par-dessus. Demandez à votre agence un accès administrateur à ce conteneur : il vous appartient, car c'est votre site et vos données. Avec cet accès, vous pouvez vérifier ce qui tourne et compléter le suivi vous-même.

Il faut aussi installer Google Analytics ?

Oui, mais après GTM, et à travers lui. C'est justement l'intérêt : une fois GTM posé, Google Analytics 4 s'ajoute depuis l'interface de GTM en quelques clics, sans retoucher le site. Vous évitez ainsi les doublons, la cause la plus fréquente de chiffres faux.
