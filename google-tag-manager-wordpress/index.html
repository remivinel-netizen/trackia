Installer Google Tag Manager sur WordPress : 3 méthodes, sans développeur

Sur WordPress, le plus simple est l'extension gratuite GTM4WP : vous l'installez, vous collez votre identifiant GTM, et elle pose le code sur toutes les pages. Comptez 5 minutes. Deux autres méthodes existent, par une extension d'insertion de code ou par votre thème. Dans tous les cas, deux vérifications font la différence : vos extensions de cache ne doivent pas bloquer Google Tag Manager, et il ne doit être installé qu'une seule fois.

Avant de commencer

Il vous faut deux choses : un accès administrateur à votre site WordPress, et un compte Google Tag Manager avec son conteneur. Si vous n'avez pas encore de conteneur, créez-le d'abord : notre guide pour installer Google Tag Manager sur un autre type de site explique cette étape, valable pour tous les sites.

À la création du conteneur, Google Tag Manager affiche deux morceaux de code et un identifiant de la forme GTM-XXXXXXX, en haut à droite de l'écran. Selon la méthode choisie, vous aurez besoin soit de l'identifiant seul, soit des deux morceaux de code. Gardez cet onglet ouvert.

Un point à vérifier avant tout : si votre site est hébergé sur WordPress.com, et non sur un hébergement classique, l'installation d'extensions n'est possible qu'avec une offre payante qui les autorise. Sur un site WordPress installé chez un hébergeur, comme la plupart des sites d'artisans, aucune restriction.

Méthode 1 : l'extension GTM4WP, la plus simple

GTM4WP est une extension gratuite, très répandue, dédiée à Google Tag Manager. Elle ne demande que l'identifiant, et place elle-même les deux morceaux de code au bon endroit, sur toutes les pages.

  1. Dans votre administration WordPress, ouvrez Extensions, puis Ajouter. Cherchez « GTM4WP ».
  2. Cliquez sur Installer maintenant, puis sur Activer.
  3. Ouvrez Réglages, puis Google Tag Manager. Collez votre identifiant GTM-XXXXXXX dans le champ prévu.
  4. Laissez les autres options par défaut, puis enregistrez.

C'est la méthode que nous recommandons : elle survit aux changements de thème, et l'identifiant se modifie en un clic si besoin. L'extension propose aussi, dans ses onglets d'intégration, des options pour signaler certains événements, comme l'envoi de formulaires Contact Form 7. Vous n'en avez pas besoin pour l'installation.

Méthode 2 : une extension d'insertion de code

Si vous utilisez déjà une extension qui ajoute du code dans l'en-tête de vos pages, comme WPCode, vous pouvez vous en servir plutôt que d'en installer une nouvelle.

  1. Ouvrez la page de l'extension consacrée à l'en-tête et au pied de page. Dans WPCode, elle s'appelle « Header & Footer ».
  2. Collez le premier morceau de code de Google Tag Manager dans la zone de l'en-tête, appelée Header.
  3. Collez le second morceau, celui qui commence par <noscript>, dans la zone du début de page, appelée Body.
  4. Enregistrez.

Attention à bien placer chaque morceau dans sa zone : le premier doit être le plus haut possible dans l'en-tête. Inverser les deux est une erreur fréquente.

Méthode 3 : votre thème ou votre constructeur de pages

Certains thèmes et constructeurs de pages ont un champ prévu pour les codes de suivi. Divi le propose dans les options du thème, onglet Intégration. Elementor le propose avec sa version payante, dans la rubrique Code personnalisé. D'autres thèmes ont une option similaire.

Cette méthode fonctionne, mais elle a deux limites :

  • le code disparaît si vous changez de thème, et personne ne s'en rend compte avant de voir les conversions s'arrêter ;
  • si vous modifiez directement les fichiers du thème, sans thème enfant, une simple mise à jour du thème efface votre code.

Si vous avez le choix, préférez la méthode 1.

Les réglages de cache et d'optimisation à vérifier

C'est le piège propre à WordPress. Les extensions qui accélèrent votre site, comme WP Rocket, LiteSpeed Cache, Autoptimize ou Perfmatters, peuvent retarder ou modifier le chargement des scripts. Certaines options vont jusqu'à attendre que le visiteur bouge la souris ou fasse défiler la page avant de lancer les scripts.

Pour Google Tag Manager, les conséquences sont réelles : des visites non comptées, et surtout un numéro de clic sur l'annonce qui peut être perdu avant d'être mis de côté. Après l'installation, vérifiez trois choses dans votre extension de cache :

  • si une option retarde l'exécution du JavaScript, excluez-en Google Tag Manager, en ajoutant googletagmanager.com à la liste des exclusions ;
  • si une option combine ou réduit les fichiers JavaScript et que Google Tag Manager se comporte mal, excluez-le aussi ;
  • videz le cache de l'extension, puis celui de votre hébergeur s'il en a un, pour que tous les visiteurs reçoivent la nouvelle version des pages.

Vérifier l'installation avec Tag Assistant

  1. Dans Google Tag Manager, cliquez sur Prévisualiser, en haut à droite.
  2. Tag Assistant s'ouvre dans un nouvel onglet : tapez l'adresse de votre site et cliquez sur Connect.
  3. Votre site s'ouvre dans une fenêtre. Revenez sur l'onglet Tag Assistant : il doit afficher « Connecté ! » avec votre identifiant GTM.

Si Tag Assistant ne se connecte pas, ouvrez une page de votre site dans une fenêtre de navigation privée, faites un clic droit, choisissez Afficher le code source, et cherchez « GTM- ». Si l'identifiant n'apparaît pas, le code n'est pas posé, ou une ancienne version de la page est encore en cache.

Les erreurs fréquentes sur WordPress

  • Google Tag Manager installé deux fois. Par exemple avec GTM4WP et dans les options du thème. Chaque visite est alors comptée en double. Gardez une seule méthode.
  • Site Kit de Google qui fait doublon. L'extension officielle de Google peut placer elle-même la balise de Google Analytics. Si vous configurez aussi Google Analytics dans Google Tag Manager, vos statistiques sont doublées. Décidez d'un seul endroit.
  • Un code collé dans un article ou une page. Le code doit être sur toutes les pages, pas dans le contenu d'une seule.
  • Une installation faite sur le site de test. Si votre hébergeur propose une copie de préproduction, vérifiez que le code est bien sur le site en ligne.

Questions fréquentes

GTM4WP est-elle gratuite ?

Oui. L'extension est gratuite et suffit entièrement pour installer Google Tag Manager sur un site WordPress. Elle ne demande aucun compte supplémentaire.

Faut-il aussi installer Site Kit de Google ?

Ce n'est pas nécessaire. Site Kit sert surtout à afficher des statistiques dans votre administration WordPress. Si vous l'utilisez, veillez à ne pas placer la balise de Google Analytics à la fois par Site Kit et par Google Tag Manager, sinon vos visites seront comptées deux fois.

Google Tag Manager va-t-il ralentir mon site WordPress ?

Très peu. Son code se charge sans bloquer l'affichage des pages. Ce sont les balises qu'on y ajoute qui pèsent, et quelques balises Google ont un effet négligeable sur un site d'artisan ou de TPE.

Mon site est sur WordPress.com, est-ce possible ?

Oui, à condition d'avoir une offre payante qui autorise les extensions. Avec une offre qui ne les autorise pas, vous ne pourrez pas installer GTM4WP ni coller le code de Google Tag Manager.
