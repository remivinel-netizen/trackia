Google Tag Manager, c'est quoi ? L'explication simple pour les non-techniciens

Google Tag Manager, souvent abrégé GTM, est un outil gratuit de Google qui sert à ajouter et à gérer les codes de mesure de votre site : statistiques, publicité, conversions. On installe un seul code sur le site, une fois pour toutes. Ensuite, tout se règle depuis l'interface de Google Tag Manager, sans retoucher le site et sans développeur.

À quoi sert Google Tag Manager ?

Chaque outil de mesure demande d'ajouter son propre code sur votre site : un pour Google Analytics, un pour Google Ads, un autre pour suivre les demandes de devis. Sans Google Tag Manager, chaque ajout ou modification passe par le site lui-même, donc souvent par un développeur ou par votre agence.

Google Tag Manager fonctionne comme un tableau électrique. On le pose une fois, au bon endroit. Ensuite, on branche, débranche et règle chaque appareil depuis le tableau, sans rouvrir les murs. Vos codes de mesure sont les appareils, et le site n'a plus besoin d'être touché.

Pour un artisan ou une TPE qui fait de la publicité sur Google, cela change trois choses :

  • vous pouvez mesurer vos demandes de devis sans faire appel à un développeur ;
  • vous voyez en un seul endroit tout ce qui mesure votre site ;
  • vous testez chaque réglage avant de le mettre en ligne, sans risque pour le site.

Les quatre mots à connaître

L'interface de Google Tag Manager impressionne au premier abord. Pourtant, quatre notions suffisent pour comprendre l'essentiel.

MotCe que c'estExemple
ConteneurLa boîte qui contient tous vos réglages, propre à votre site.Le conteneur de votre-site.fr, avec son identifiant GTM-XXXXXXX.
BaliseUne action à réaliser, comme envoyer une information à Google Analytics.« GA4 - Demande » : signaler une demande de devis.
DéclencheurLe moment où la balise doit agir.« Formulaire envoyé » : au moment où le visiteur valide le formulaire.
VariableUne information que les balises peuvent utiliser.Le numéro du clic sur l'annonce, ou le nom de la page.

Une phrase résume tout : une balise fait quelque chose, au moment fixé par son déclencheur, en utilisant des variables. Tout le reste de l'interface sert à organiser ces trois éléments.

Google Tag Manager, Google Analytics, Google Ads : qui fait quoi

La confusion est fréquente, car les trois outils portent le nom de Google et travaillent ensemble.

OutilSon rôle
Google Tag ManagerIl pose et déclenche les codes de mesure. Il ne mesure rien lui-même.
Google Analytics 4Il compte et range les visites et les actions : pages vues, demandes envoyées, origine des visiteurs.
Google AdsIl diffuse vos annonces, et reçoit les conversions pour savoir lesquelles rapportent.

Google Tag Manager est donc le chef d'orchestre : c'est lui qui envoie, au bon moment, les bonnes informations à Google Analytics et à Google Ads.

Un exemple concret : compter une demande de devis

Voici ce qui se passe, dans l'ordre, quand un visiteur envoie le formulaire de contact d'un site équipé de Google Tag Manager.

  1. Le visiteur clique sur « Envoyer ». Le site signale cet envoi à Google Tag Manager, sous la forme d'un petit message.
  2. Google Tag Manager reconnaît ce message grâce à un déclencheur réglé à l'avance, par exemple « Formulaire envoyé ».
  3. Ce déclencheur active la balise associée, « GA4 - Demande ». Elle envoie à Google Analytics 4 l'information qu'une demande de devis vient d'arriver.
  4. Google Analytics 4 compte la demande, et la transmet à Google Ads comme conversion si les deux comptes sont reliés.

Rien de tout cela n'est écrit dans le code du site. Le jour où vous changez de formulaire, vous ne modifiez que le déclencheur dans Google Tag Manager, et la mesure repart.

Est-ce que Google Tag Manager ralentit le site ?

Très peu. Le code de Google Tag Manager se charge sans bloquer l'affichage de vos pages. Ce qui pèse, ce sont les balises qu'on y ajoute : quelques balises Google ne changent presque rien, plusieurs dizaines d'outils différents finissent par se sentir. Pour un site d'artisan ou de TPE, avec Google Analytics et le suivi Google Ads, l'effet est négligeable.

Est-ce compliqué à utiliser ?

L'interface est dense, car elle sert aussi aux grandes entreprises. Une petite entreprise n'en utilise qu'une petite partie : quelques balises, quelques déclencheurs. Deux fonctions rendent l'outil rassurant pour un débutant :

  • le mode Aperçu, qui ouvre votre site dans un mode test et montre quelles balises se déclenchent, sans rien changer pour vos visiteurs ;
  • les versions : chaque publication est enregistrée, et vous pouvez revenir à la précédente en un clic si quelque chose ne va pas.

Une erreur revient souvent chez les débutants : modifier ses réglages et oublier de cliquer sur Envoyer, puis Publier. Tant que ce n'est pas fait, rien n'est en ligne. Pour aller plus loin, notre page pour apprendre à utiliser Google Tag Manager présente les trois sujets à maîtriser, dans l'ordre.

Questions fréquentes

Google Tag Manager est-il gratuit ?

Oui, entièrement, pour tous les sites. Il existe une version payante destinée aux très grandes entreprises, dont une petite entreprise n'a pas besoin.

Faut-il savoir coder pour utiliser Google Tag Manager ?

Non pour l'essentiel. On choisit des balises et des déclencheurs dans des menus. Le seul code à manipuler est celui qu'on colle une fois sur le site lors de l'installation, et la plupart des outils de création de site ont une option ou une extension pour le faire sans toucher au code.

Quelle différence entre Google Tag Manager et la balise Google ?

La balise Google est le code d'un outil Google, comme Google Analytics ou Google Ads. Google Tag Manager est le gestionnaire qui peut contenir cette balise, et beaucoup d'autres. Avec Google Tag Manager, la balise Google se règle depuis l'interface, sans être collée dans le site.

Google Tag Manager est-il compatible avec le RGPD ?

Google Tag Manager lui-même ne dépose pas de cookie. Ce sont les balises qu'il déclenche qui en déposent, et elles doivent respecter le choix du visiteur. Avec un bandeau cookies relié au mode de consentement de Google, les balises attendent l'accord du visiteur.
